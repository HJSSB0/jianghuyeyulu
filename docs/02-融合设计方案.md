# 《江湖夜雨录》融合设计方案

> 版本 v1.0 ｜ 2026-11-05 ｜ 依据：`01-调研拆解对比.md` 第 8 节融合结论
> 形态：Godot 4.7 垂直切片（约 1-2 小时可玩内容）｜像素图+文本面板混合美术

---

## 1. 游戏概述

- **暂定名**：《江湖夜雨录》（Jianghu Night Rain）
- **题材**：南宋风武侠。玩家从雨夜的无名小村幸存者起步，习武、择派、结友，卷入拜月教（魔教）渗入江湖的阴谋第一章。
- **一句话**：大侠立志传的「江湖生态与自由构建」× 烟雨江湖的「站位策略与养成长线」。
- **平台**：Godot 4.7 / GDScript / 960×540 像素风窗口，程序化美术零外部素材。

## 2. 融合决策映射表（核心机制溯源）

| # | 机制 | 源自 | 融合取舍与原因 |
|---|---|---|---|
| F1 | 九宫格 3×3 站位、上中下三路 | 烟雨 | 低操作高策略的结构层；近战默认打对位前排，远程/指定路可选 |
| F2 | ATB 时序条（身法→集气速率） | 大侠 | 把「速度」变成持续资源；回合制节奏感 |
| F3 | 战意 0-200：100 解锁绝招、200 必爆 | 大侠 | 战斗爆发节奏点；攻受击均积攒，敌我通用 |

## 3. 核心玩法循环

```
        ┌────────────────────────────────────────────────┐
        │                                                │
   [探索] 城镇/野外 tile 行走（时辰流动）                    │
        ↓                                                │
   [触发] 事件/奇遇/悬赏/遭遇/可交互 NPC                     │
        ↓                                                │
   [应对] 九宫格 ATB 战斗 ═══ 或 ═══ 社交(送礼/切磋/易物/请教)│
        ↓                                                │
   [收获] 铜钱/材料/武学秘籍/装备/好感/修为/品格变化           │
        ↓                                                │
   [修炼] 打坐(时辰推进):武学升重 / 通经脉 / 炼丹烹饪          │
        ↓                                                │
   [进阶] 名声/品格/门派关系成长 → 解锁门派线+主线分支         │
        ↓                                                │
   [章节] 拜月教阴谋推进 → 第 1 章 Boss → 3 结局之一          │
        └──── 新周目钩子（结局后提示）◄──────────────────────┘
```

**分钟级循环**：走图→交互→战斗/对话→获得→变强。
**小时级循环**：门派任务链→招募随从→凑齐三件套→突破境界→通经脉。
**章节级循环**：主线分支选择→品格阵营变化→结局。

```
│   ├── Title.tscn / CharCreate.tscn / Ending.tscn
│   ├── Overworld.tscn       # 大地图(节点图)+城镇内 tile 行走 二合一场景
│   ├── Battle.tscn          # 双九宫格+ATB 条+技能面板+文本战斗日志
│   └── ui/                  # dialogue_panel / status_menu / inventory / shop / bounty_board ...
├── data/                    # 数据与逻辑分离（全部 JSON）
│   ├── wuxue.json           # 30 门武学（套路/内功/轻功×品级×招式×词条）
│   ├── items.json           # 物品：装备/消耗/材料/礼物/秘籍（60+）
│   ├── npcs.json            # NPC 30+（位置/对话/好感偏好/可交互）
│   ├── quests.json          # 主线+门派+悬赏+随从任务（25+）
│   ├── encounters.json      # 奇遇事件（10+ 多条件）
│   ├── factions.json        # 3 门派（加入条件/任务链/武学/退门）
│   ├── formations.json      # 4 阵法
│   ├── meridians.json       # 8 经脉顺逆效果
│   ├── traits.json          # 特性池 12+
│   ├── shops.json           # 商店/黑市
│   ├── maps.json            # 大地图节点+4 张 tile 地图+采集点+隐藏点
│   └── recipes.json         # 炼丹/烹饪配方
├── .zcode/
│   ├── HANDOFF.md
│   └── tests/               # headless 冒烟测试（godot --headless --script 运行）
└── .tools/                  # Godot 4.7.2 便携版（已就位）
```

**分层原则**：
1. **逻辑层零场景依赖**——autoload 五件套可完全 headless 运行，测试不碰渲染。
2. **数据全 JSON**——数值调整不改代码；GameDB 启动校验引用完整性（技能引用、任务奖励物品存在性）。
3. **UI 只读逻辑层**——通过 EventBus 订阅变化，符合"像素画面+文本面板"混合形态。

## 6. 数值框架（垂直切片版）

### 6.1 五维 → 战斗面板换算（主角初始 15 点分配，单项 1-8）

- 臂力：攻击 +2/点；拳/刀套路加成系数
- 体质：气血 +12/点、防御 +1/点
- 敏捷：速度 +2/点（决定 ATB 集气）、闪避 +1%/点
- 悟性：修为获取 +5%/点；武学突破修为消耗 -4%/点
- 福缘：暴击 +0.5%/点；奇遇触发权重 +5%/点；采集品质

### 6.2 等级与成长曲线（统一公式，规避大侠数值失衡）

- 经验：`exp(lv) = 30 * lv^1.6`；1 级→10 级（首章上限 10）
- 敌人强度模板：`面板 = 基础 * (1 + 0.18 * (lv-1))`，同名敌人跨地图只调 lv
- 品级基准攻击：丁 12 / 丙 18 / 乙 26 / 甲 36（每重境界 +12%）

### 6.3 战斗数学

- 伤害 = `atk * 技能倍率 * (1 - def/(def+120)) * 词条修正 * 阵法修正 * 侧背/突进修正`
- 命中 = `85% + 命中值 - 目标闪避`（下限 30% 上限 100%）
- ATB：行动阈值 1000；集气/秒 = `8 + 速度*0.6`；轻功 +15% 集气
- 战意：造成/受到伤害 +12/10；绝招消耗 100；满 200 下次攻击必爆（爆伤 160%）
- 三路规则：近战技能默认对位路最近存活目标；「突进」词条直达后排；群体技能按路

### 6.4 经济定价（铜钱为主，1 银两=1000 铜钱）

- 开局 300 铜；悬赏丙/乙/甲 = 200-400/600-900/1200-2000 铜
- 采集单次产出 15-40 铜；炼丹利润率约 50%；长租房 2000 铜
- 装备丁丙乙甲 ≈ 150/500/1500/4000 铜；礼物 50-500 铜

## 7. 内容清单（垂直切片）

- **地图**：无名小村（教程）+ 江州城（主城：门派引路人/悬赏/黑市/客栈）+ 临安镇（副城：伏虎禅寺山门/渔村）+ 铁剑门 / 伏虎禅寺 / 烟波楼 3 门派场景 + 2 野外点（随机遭遇+采集）

- **结局**：3（剑指拜月·入世 / 归隐小村·出世 / 暗渊沉沦·接任，按品格+选择分支）
