# 《大侠立志传》×《烟雨江湖》系统拆解对比报告

> 调研日期：2026-11-05 ｜ 调研方式：联网检索（Steam/官网/Wiki/TapTap/游民星空/17173/知乎/B站Wiki/巴哈姆特等，来源清单见文末）
> 用途：为融合游戏《江湖夜雨录》的设计提供系统化依据。

---

## 0. 两款游戏概览

| 维度 | 《大侠立志传》 | 《烟雨江湖》 |
|---|---|---|
| 开发 | 半瓶醋工作室（XD 发行） | 杭州蓝鲸工作室（编剧罗希林） |
| 形态 | PC/手游，像素开放世界武侠 RPG | 手游（TapTap/iOS），水墨文本+地图混合 RPG |
| 发售 | 2023-03 EA；2023-11 正式版《碧血丹心》 | 2019 年前后 |
| 定位 | 「江湖生存模拟器」：高自由度非线性 | 「电子武侠小说」：慢节奏深度养成 |
| 官方数据 | 30+ 门派势力、300+ 武学、80 城镇、10+ 结局 | 镇派武学 111 门、7 入门派、主线 12 卷 |
| 口碑 | Steam 特别好评（93%）；差评集中在数值/引导 | TapTap 5.9/10 两极分化；文案剧情口碑最高 |

**一句话定位差异**：大侠立志传卖「自由与生态」（无数值网状交织的活江湖），烟雨江湖卖「深度与文案」（以天为单位的长线养成+高质量文本）。

---

## 1. 战斗系统对比

| 子项 | 《大侠立志传》 | 《烟雨江湖》 |
|---|---|---|
| 战斗形式 | 半即时 ATB 时序条 + 大地图战棋走格 | 纯回合制，速度决定出手顺序 |
| 站位 | 距离/朝向/地形（战棋空间） | **九宫格**：上中下三路 × 前中后三列，上阵 4 人 |
| 行动顺序 | 集气速度驱动头像时序条，到顶行动 | 速度属性排序列表 |
| 资源机制 | **战意 0-200**：100 放绝招、200 必爆 | **真元/聚气**：聚气攒真元放大招 |
| 队伍 | 主角+最多 5 队友=6 人，宠物参战 | 主角+3 随从=4 人 |
| 策略层 | 侧/背攻加成、技能射程、冷却 | **阵法 12+种**（阵眼+方位加成）、分路策略（202/112 黑话） |
| 武学装配 | 9 格武功栏自由装配、主/副内功位 | 每角色 1 套路+1 内功+1 轻功 |
| 属性细节 | 五维间接影响；状态：封穴/内伤/中毒/致盲 | 命中/闪避/招架/韧性/罡气/内劲/免伤/破甲；DOT 抗性 |
| 特色机制 | 自动战斗+4 倍速 | **战斗序列伪随机**：玩家行为可重排序列 |
| 演出 | 像素走格演出 | 数值对撞+文本演出 |

**分析**：
- 大侠的 ATB 时序条把「速度」变成持续博弈资源（集气快=行动多），战意提供爆发节奏点；但走格战棋在手游/轻量实现里成本高。
- 烟雨的九宫格+阵法是**低操作成本、高策略密度**的典范：分路站位决定受击面，阵法决定全队风格；序列机制给回合制加入了"操作感"。
- **融合方向**：九宫格承载站位/阵法/分路策略（结构层）+ ATB 时序条承载行动节奏（时间层）+ 战意承载爆发（资源层），三者正交可叠加。

## 2. 成长养成对比

| 子项 | 《大侠立志传》 | 《烟雨江湖》 |
|---|---|---|
| 基础属性 | **五维**：臂力/体质/敏捷/悟性/福缘，开局 15 点 | 攻/防/血/速度/命中/闪避/招架/韧性等战斗面板 |
| 武学结构 | 内功(被动)+外功(主动)，300+ 门，**品级 丁丙乙甲→绝品** | **三件套：套路+内功+轻功**，品阶 基础→一般→进阶→上乘→镇派 |
| 武学升级 | 修炼制：一次主修一门，战斗攒经验；江湖历练点另池 | **修为系统**：十重境界×每重三层；升重消耗阅历+真实时间（365 小时时间墙） |
| 特色养成 | 武道天赋树六系（风林火山阴雷）；双同品合成升品 | **经脉：十二正经+奇经八脉，每条顺通/逆通效果不同**；洗脉天赋 |
| 道德/人格 | **品格六维**（仁义礼智信勇 ±100）激活特征、联动队友好感 | 无（有善恶分支选项但不系统化） |
| 人际 | 好感 0-100、结缘（恋爱 18-25 人）、结义、门派关系 | 好感度（150 体力=1 好感）、小势力好感 11 个（贡献制） |
| 名声 | 名声等级制：送礼加成/事件门槛/解锁家园 | 声望 300 解锁宅府购地 |
| 伙伴 | 队友 50+ 可入队，各有任务链 | 随从 10+（剧情三选一+元宝随从），传功转移武学 |
| 生活技能 | 采集 5 类+口才/经商/暗取/点穴等 10 项全练级制 | 技艺：酒艺/烹饪/垂钓/炼丹/音律等 12+ 门 |
| 多周目 | **轮回制**：成就点换开局特性、家园跨存档继承 | 无（单局长线） |

**分析**：
- 大侠的「五维+特性 Roll+品格」构成**开局人格化构建**，玩家从第一分钟就在"捏一个侠客"；品格六维是罕见的"道德数值化"设计。
- 烟雨的「三件套+十重境界+经脉顺逆」构成**长线深度**，每一步都有目标；但时间墙（真实 365 小时）是被骂最多的设计。
- **融合方向**：五维+特性（人格层）× 三件套+品级+境界（武学层）× 经脉顺逆（经脉层）× 品格三维简化版（道德层）；**所有等待压缩到游戏内时辰级，坚决不做现实时间墙**。

## 3. 任务剧情对比

| 子项 | 《大侠立志传》 | 《烟雨江湖》 |
|---|---|---|
| 主线 | 「楚襄之殇」三线分支（叶家军/燕云铁军/九流门） | 12 卷单线主线（忘忧村→四玉玦→武神殿→诸葛长空） |
| 多结局 | **10+ 结局**（守护者/与虎谋皮/武林霸主/归隐/大量恶搞） | **无多结局**（玩家批评点） |
| 门派剧情 | 可加入 10 门派，完整任务链，可退门身兼多派 | 7 入门派各有镇派线+出师+判门长线规划 |
| 支线/奇遇 | **多条件网状触发**（时辰/好感/名声/携带物），1.0 版 100+ 新事件 | 奇遇四类触发（走图/打听/属性门槛/持有道具），数量极大 |
| 引导 | 弱（正式版加怪老头教程+风闻台） | 极弱（隐藏任务必须查攻略） |
| 文案质量 | 广而不深（靠事件广度） | **口碑护城河**（"像经历一部写得不错的武侠小说"） |
| NPC 深度 | 全命名 NPC 可送礼/切磋/易物/暗取/结缘/结义 | NPC 可深度交互甚至击杀，坐标化隐藏 |

**分析**：大侠赢在**结构**（分支/结局/网状触发），烟雨赢在**文本**（主线燃点/门派叙事）。融合：烟雨级文案标准 + 大侠式分支结构与多结局钩子。

## 4. 地图探索对比

| 子项 | 《大侠立志传》 | 《烟雨江湖》 |
|---|---|---|
| 世界结构 | 开放大世界+80 城镇独立场景 | 章节解锁式大地图（忘忧村→洛阳→…→敦煌） |
| 城镇内 | tile 场景自由行走，私物规则（红/白物品） | 坐标网格地图（NPC 在 (23,17) 这类精确坐标） |
| 时间 | **十二时辰**驱动 NPC 位置/事件/营业时段 | 时辰系统（子时偷藏经阁、鬼市刷新） |
| 隐藏内容 | 藏宝图/兽环/悟道之地，多条件奇遇 | 坐标搜索点/轻功门槛（轻功 120 免绳索） |
| 采集 | 甲乙丙丁四级资源点，按时辰恢复周期 | 钓鱼/挖矿/采药日常，地点收益差异 |
| 移动 | 宠物坐骑快速旅行 | 轻功决定移动/探索能力 |

**分析**：两者共享「时辰驱动世界」的武侠时间观。融合：节点式大地图（低成本）+ 城镇 tile 行走 + 时辰事件网 + 定时恢复的采集点 + 轻功/属性门槛的隐藏点。

## 5. 经济系统对比

| 子项 | 《大侠立志传》 | 《烟雨江湖》 |
|---|---|---|
| 货币 | 铜钱（文/贯）/银两 | 铜钱→银两→元宝（充值） |
| 核心收入 | 悬赏委托板（甲乙丙级）、易物、拍卖、擂台 | 押镖、采集售卖、挂机托管、副本、地质录 |
| 生产 | 琅琊剑阁学打造、道玄宗学炼药 | 炼丹/烹饪/酿酒技艺（蒸炒炖分支、48h 酿酒） |
| 交易特色 | **易物**（好感门槛+信用加成）、夜摩坊拍卖 | 鬼市（每日 2 次刷新）、门派/势力贡献商店 |
| 家园 | 名声解锁，六区+伙伴进驻+跨周目继承 | 宅府六档（40 两→3000 元宝），游历/酒窖/梅花桩 |
| 付费模型 | 买断+DLC | F2P：月卡+元宝随从（克制但拖时长） |

**分析**：大侠的经济挂在**人际网**上（易物/信用/名声加成），烟雨的经济挂在**日程**上（日常清单+每日上限）。融合：悬赏+采集+炼制的多收入渠道，易物作为好感的变现出口，客栈长租房作为简化家园。

## 6. 设计特色提炼（各自 Top 5）

**大侠立志传**：
1. 开放式角色构建（15 点五维+特性 Roll+9 格武学自由装配）
2. 四层人际数值网（好感×门派关系×品格六维×名声）互相触发事件
3. 时序条战斗（集气+战意+侧背攻）
4. 时辰系统让"时间成为探索资源"
5. 轮回多周目+家园跨存档继承

**烟雨江湖**：
1. 九宫格站位+阵法的低操作高策略战斗
2. 武学三件套+十重境界+修为的养成长线
3. 经脉顺通/逆通的双择一构筑
4. 剧情文案质量（"活的江湖"）
5. 慢节奏日积月累的回报感（每日上限防肝爆/防氪碾压）

## 7. 弱点规避清单（融合设计必须回避）

| # | 来源 | 弱点 | 规避策略 |
|---|---|---|---|
| 1 | 烟雨 | 现实时间墙（365h 突破、48h 酿酒） | 所有等待 ≤ 游戏内时辰级；真气分钟级恢复 |
| 2 | 大侠 | 数值平衡差、同级武学同质化 | 统一成长曲线公式；同级武学差异化子词条 |
| 3 | 大侠 | 引导缺失，新手迷失 | 新手村老者教程链+风闻提示系统 |
| 4 | 两者 | 肝度过高、机械日常 | 垂直切片不做每日打卡；采集/悬赏可选不做强制 |
| 5 | 烟雨 | 剧情线性无多结局 | 主线首章即设 3 结局钩子 |
| 6 | 两者 | 隐藏内容必须查攻略 | 奇遇给渐进提示（NPC 传闻→坐标线索） |
| 7 | 大侠 | SL 依赖（随机惩罚倒逼读档） | 随机失败给保底收益 |
| 8 | 烟雨 | 氪金拖时长 | 单机买断式设计，无付费墙 |

## 8. 可融合要素结论

**结构性结论**：两款游戏的能力矩阵几乎互补——

| 层面 | 取自大侠立志传 | 取自烟雨江湖 |
|---|---|---|
| 战斗-时间层 | ATB 时序条+战意绝招/必爆 | — |
| 战斗-空间层 | 突进/侧背概念 | 九宫格+分路+阵法 |
| 战斗-装配层 | 武学栏自由装配思想 | 套路/内功/轻功三件套 |
| 养成-人格层 | 五维+特性 Roll+品格 | — |
| 养成-武学层 | 品级丁丙乙甲 | 境界层数+修为+经脉顺逆 |
| 养成-人际层 | 好感+结义+门派关系 | 随从+传功 |
| 剧情层 | 分支+多结局+奇遇网状触发 | 文案标准+门派叙事 |
| 世界层 | 时辰+采集周期+名声门槛 | 章节地图+隐藏搜索点+轻功门槛 |
| 经济层 | 悬赏+易物 | 技艺生产+宅府 |

以上映射直接指导《江湖夜雨录》设计方案（见 `02-融合设计方案.md`）。
